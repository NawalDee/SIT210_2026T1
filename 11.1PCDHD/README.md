# Smart Medication Monitoring System

## Description
This project monitors medication schedules using Arduino Nano 33 IoT, Load Cell, MQTT, Python GUI, and IFTTT notifications.

## Hardware
- Arduino Nano 33 IoT
- HX711
- Load Cell
- LCD Display
- LEDs
- Buzzer

## Software
- Python
- MQTT
- Tkinter
- Paho MQTT

## How to Run
1. Upload Arduino code.
2. Run the Python GUI.
3. Add a patient.
4. Add medicines.
5. Start monitoring.

## MQTT Topics
medication/start
medication/setup
medication/reminder
