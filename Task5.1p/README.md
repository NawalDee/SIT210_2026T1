
Overview

This project uses a Raspberry Pi and a GUI (Tkinter) to control lights in different rooms. The user can select a room and turn ON the corresponding LED.

#Features:

Living Room → LED ON

Bathroom → LED ON

Closet → LED ON

Only one LED works at a time

Simple GUI with radio buttons

Exit button to close the program


#How It Works?

The user selects a room using the GUI

The selected room LED turns ON

All other LEDs turn OFF

 
#Hardware Used:

Raspberry Pi

3 LEDs

Resistors

Breadboard & jumper wires


#Software Used:

Python

gpiozero

tkinter


#How to Run?

Connect the circuit to Raspberry Pi

Run the program:

python3 main.py

Use the GUI to control the lights
