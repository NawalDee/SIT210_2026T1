Description:

This project uses an Arduino Nano 33 IoT to read temperature and light data and send it to ThingSpeak. The data is displayed as graphs on the web.

Components:
Arduino Nano 33 IoT
DHT11 sensor
Light sensor

How it works:
Temperature is read from DHT11
Light is read from A0
Data is sent to ThingSpeak using WiFi
Graphs show the data online
